# CLAUDE.md

The rules for this repo live in [AGENTS.md](./AGENTS.md). Read it before changing anything under `skills/`.

The short version: a skill is not done until it has a `README.md` written with the `docs` skill, and the root `README.md` lists it in all three places (the skills table, "Why each one is cool", and "Repo layout"). Docs go in the same commit as the skill.
