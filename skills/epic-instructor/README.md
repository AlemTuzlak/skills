# epic-instructor

Apply Kent C. Dodds' "How to be an Epic Instructor" principles when creating workshops, exercises, tips, or recorded videos in the Epic Web / Epic React style.

## What it does

Encodes the seven Epic-instructor principles (opinions and consistency, avoid distraction, problems before solutions, desirable difficulties, experience-based instruction, instructors make their own demos, give freely) and the operational details for running and recording an Epic-style workshop — structure, video categories, logistics defaults, and recording rules.

When invoked it walks through:

1. Topic + target audience clarification (with the same-app heuristic for "should we teach X or Y")
2. Experience check — has the instructor actually shipped with this tech?
3. Exercise progression outline (so domain-specific exercises always sit on top of prior onboarding)
4. Problem-before-solution framing for each exercise
5. Live-delivery cadence before recording
6. Scope — single workshop vs. split

## When to invoke

Trigger on any of:

- "Create a workshop", "design a workshop", "plan a workshop"
- "Record a workshop video", "record an exercise video"
- "Epic Web", "Epic React", "Epic instructor", "epicweb.dev"
- Designing exercises, tips, or workshop app material
- `/epic-instructor`

## Output

Guidance, checklists, and red-flag pushback against proposed material — not code. The skill helps shape the workshop *before* exercises get written and recorded.
