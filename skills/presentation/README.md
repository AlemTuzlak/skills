# presentation

Shared talk craft for Slidev and Three.js engines.

Do not run this skill alone. Load it from `slidedev-presentation` or
`threejs-presentation`.

## What it does

1. **Researches + grounds first.** Deep web research on the topic, and for a
   specific library, the real code. Talks are built from a cited brief.
2. **Interviews you.** Audience, per-area depth, duration, takeaway, tone,
   notes, brand, diagrams, assets, output folder.
3. **Storyboards for approval** before any engine writes slides or a world.
4. **Applies craft.** Assertion-evidence titles, one idea per slide, text
   budget, code discipline, no fake evidence.

## Trigger it

Do not. Use `/slidedev-presentation` or `/threejs-presentation`. Those skills
load this one.

## Layout

```
SKILL.md                       library rules, gates, non-negotiables
references/
  research-grounding.md        Gate 1: topic research + code grounding
  interview.md                 core questions + slide-count math
  presentation-craft.md        general craft + myth-flags
  technical-craft.md           code, diagrams, demos, audience
  assets.md                    never fabricate, placeholders
```
